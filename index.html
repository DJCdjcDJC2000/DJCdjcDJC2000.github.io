🎯Graduation Project

Sparse Spectral Methods for a Class of Optimal Control Problems

🥇 First Place — Thesis Proposal & Mid-term Defense
  • Identified limitations of traditional node-based pseudo-spectral methods (dense coefficient matrices, computational inefficiency)
  • Proposed a modal basis pseudo-spectral method using Chebyshev polynomials of the first kind to approximate unknown functions
  • Transformed dynamic constraints into Chebyshev approximation coefficient equality constraints, discretizing the optimal control problem into a sparse-band nonlinear programming problem
  • Implemented in Python, achieving excellent accuracy and convergence speed; verified algorithm advantages via condition number analysis
  • Future directions: hp spectral element method and further extensions
